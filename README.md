# Curriculum vitae

Personal CV website of Ezequiel Koulaksezian, built with Next.js, TypeScript and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All CV content lives in `src/data/cv.ts`. The downloadable PDF is `public/CV_Ezequiel_Koulaksezian.pdf`.
